## 2. Ключевой вопрос: где 3P?

По спеке (`pipeline_patch_pilot_review.md`, п. 5):

```
Фаза 1: 3A + 3B + 3C (обзоры) — ВЫПОЛНЕНО
Фаза 2: LLM-маппинг → динамическая schema и промпт для 3P — ВЫПОЛНЕНО ЧАСТИЧНО
Фаза 3: 3P — целевой запрос по параметрам через Parallel API — НЕ РЕАЛИЗОВАН
```

**Что реализовано** в нашей "Phase 2": LLM извлекает параметры **из уже собранных обзорных данных** (3A+3B+3C). Это соответствует шагу "извлечение и маппинг" из Фазы 2 спеки.

**Что не реализовано**: шаг 3P — новый целевой запрос в Parallel API с динамической schema, где для каждого найденного параметра формируется отдельный фокусированный запрос с контекстом из обзоров (конкретные правила, главы rulebook, сноски на параметры).

По спеке, 3P — это дополнительный уровень глубины поверх обзоров: обзоры дают общую картину, 3P уточняет методологию расчёта конкретных параметров с цитированием конкретных правил.

## 3. Вопросы к архитектору

**В1.** Нужно ли реализовывать шаг 3P на пилоте, или Pass 2 (извлечение значений из обзорных данных) считается достаточным для валидации пайплайна?

Аргумент "не нужно сейчас": обзорные данные (3A+3B+3C) уже содержат достаточно детального контекста для извлечения параметров; 3P добавит ещё один "прогон" Parallel API, но на пилоте качество обзоров достаточно, чтобы проверить Фазу 2.

Аргумент "нужно сейчас": без 3P нет гарантии, что методология расчёта (п. 2 из 6-вопросного шаблона) полная; именно 3P должен давать детализацию, которую обзоры дают недостаточно.

**В2.** Если 3P нужен — он запускается до или после Pass 2? То есть: Pass 2 читает из {3A+3B+3C} или из {3A+3B+3C+3P}?

По спеке — 3P идёт после Фазы 2 (маппинга), Pass 2 в нашей логике = извлечение значений. Это предполагает порядок: Pass 1 → 3P → Pass 2.

**В3.** UNKNOWN_PARAM: в Pass 1 LLM нашёл большое количество параметров вне чеклистов. Часть из них — явные кандидаты на расширение словаря (например, "Electronic settlement eligibility", "Free transferability"). Нужно ли их формализовать сейчас (до Pass 2), или логировать и передавать на масштабирование?
