## Вопрос: Source pills в ячейках матрицы (F12)

### Что такое матрица

Матричное представление (`?view=matrix`) — это обзорная таблица по ячейке листинга, где:
- **Строки** = фазы жизненного цикла (Допуск / Поддержание / Исключение)
- **Столбцы** = аспекты (Требования / Процедуры / Мониторинг / Санкции / Раскрытие)

Каждая заполненная ячейка матрицы сейчас показывает до 3 параметров (код + значение):

```
┌─────────────────────────────────────────────┐
│ П05  Free float >= 10%                      │
│ П06  Market cap >= £30 млн                  │
│ П12  История >= 3 года                      │
└─────────────────────────────────────────────┘
```

По клику на ячейку пользователь переходит во вкладочное представление, где доступен полный текст секций и все источники с выдержками.

### Что изменилось в данных

После Tasks 020–023 пайплайн теперь предоставляет полноценные **citations** (источники с типами и выдержками) для каждой секции контента, включая секции, соответствующие ячейкам матрицы. Ранее эти данные были неполными или отсутствовали.

### Суть вопроса

Источники (citations) для ячеек матрицы **доступны в данных**, но **не отображаются** в матричном виде. Нужно ли их показывать?

### Варианты

- **A)** Не показывать — матрица остаётся упрощённым обзорным видом, источники доступны по клику через вкладки
- **B)** Показывать маленький счётчик в углу ячейки (например, `3 ист.`) — даёт пользователю понимание, что данные подкреплены источниками, без перегрузки
- **C)** Другой вариант по вашему усмотрению

### Справка по прототипу

В финальном прототипе (`venues/venue.html`, матричная секция) source pills в ячейках матрицы отсутствуют — показаны только параметры. Однако на момент создания прототипа данные по citations для L3-секций были неполными, поэтому это может быть не осознанным дизайн-решением, а следствием ограничений данных.
