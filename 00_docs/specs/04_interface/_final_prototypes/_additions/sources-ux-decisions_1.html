Источники и выдержки — UX-директивы

UX-дизайнер №1 → UX-разработчик В ответ на: ux_sources_and_excerpts_for_design.md + escalation_ux1 Март 2026
Главное изменение относительно предыдущих решений: вкладка «Источники» как единственная точка доступа к источникам — отменяется. Теперь есть блочная атрибуция (field), per-record источники у каждой L4-записи, и 912 дословных выдержек в L1/L3. Это открывает inline-верификацию прямо рядом с контентом. Предыдущее решение принималось в условиях отсутствия этих данных.

Часть 1 — Ответы на вопросы эскалации

В-1 listing_authority_short — где использовать? Вариант А

Короткое название — в регулятор-стрипе. Полный текст — по клику «подробнее», разворачивается прямо под стрипом. Tooltip не подходит — текст слишком содержательный для truncation.

Регулятор-стрип с раскрытием listing_authority
Регулятор BaFin commission Орган листинга Börsengeschäftsführung
Exchange management (Börsengeschäftsführung) for the Regulated Market, decided under BörsG §§15, 32. For MTF inclusions: exchange operator (e.g., Deutsche Börse AG as Freiverkehrsträger) under private-law venue rules.

Бэкенду: в регулятор-стрип передавать listing_authority_short; полный listing_authority — в отдельный атрибут для раскрытия.

В-2а Таймлайн — в текущей итерации? Да, реализовать

Реализовать сейчас. Поле label появилось — устраняет проблему обрезанных бессмысленных подписей. Горизонтальные отрезки gantt-стиля — как в прототипе jurisdiction-card.html. Dev-компонент уже существует, достаточно подключить к label.

В-2б label как заголовок карточки в drawer Подтверждаю

label — заголовок drawer. Крупно в шапке, под ним период + тип-бейдж. Полный description_ru — тело карточки. Правильная иерархия.

В-3 Источники внутри L4-записи в drawer Вариант В

Вариант В: источники прямо внизу карточки drawer, без дополнительного клика. У L4-записей нет excerpts по дизайну пайплайна — каждый источник только строка с title и ссылкой. 2–4 источника на запись компактны. Expand только если > 4: первые 3 + «ещё N».

Детали дизайна

  • Кнопка выдержек — только если excerpts.length > 0. Текст: «N выдержек ↓»
  • Текст выдержки — Newsreader italic 12.5px. Визуально отделяет прямую речь документа от интерфейсного текста — принципиально важный сигнал для аналитика
  • Фон блока выдержек — #FAFBFF, с декоративной кавычкой слева
  • Цветовые бейджи типа: rulebook → фиолетовый, legislation → синий, government → зелёный, consultation → оранжевый, research → пурпурный
  • Ссылка — hostname из URL (не полный), открывается в новой вкладке

Правило: когда показывать кнопку «N источников» в шапке блока

  • Если для этого блока по field есть ≥1 источника → показывать кнопку с числом
  • Источников нет → кнопки нет (шапка без неё)
  • Счётчик = число L1-источников с совпадающим field

Часть 5 — Вкладка «Источники» (полная библиография)

Четыре вкладки на карточке юрисдикции — итоговый вид:

Вкладки карточки юрисдикции
Юрисдикция Регуляторный анализ 26 Термины 23 Источники 57

Вкладка «Источники»:

  • Инструменты: счётчик всего + поиск по title + фильтр по type
  • По умолчанию: первые 15 источников, кнопка «показать все»
  • Каждый источник: SourceItem с accordion excerpts
  • Без группировки по field: в библиографии деление по блокам не нужно — пользователь ищет по типу или названию документа

Часть 6 — Что меняется в прототипе jurisdiction-card.html

Изменение 1 — Блоки вкладки «Юрисдикция»

Было: блоки без источников в шапке.

Стало: кнопка «N источников» в шапке каждого блока (если есть). По клику — секция внизу блока со списком SourceItem (с excerpts там где они есть). Компонент — как в Части 3.

Изменение 2 — Drawer регуляторного анализа

Было: drawer без источников.

Стало: секция «Источники» внизу drawer — SourceItem без excerpts (L4 не имеет excerpts по дизайну). ≤4 — все сразу, >4 — первые 3 + «ещё N».

Изменение 3 — Регулятор-стрип

Было: listing_authority полный текст.

Стало: listing_authority_short + кнопка «подробнее ↓» → раскрытие полного текста. Как в демо В-1.

Без изменений: структура вкладок, двухколоночный layout, таймлайн, термины, миникарточки площадок, наднациональный блок, WGI-метрики (placeholder), схожие юрисдикции (placeholder). Всё остальное — как в текущем прототипе.
