#1 Шапка уже основного контента Исправить

Навигационная шапка (nav) имеет меньшую ширину, чем основной контент страницы — визуально они не выровнены по левому краю.

Сейчас
Шапка занимает не всю ширину viewport, логотип и меню не совпадают по левому краю с героев-контентом.
Должно быть
Шапка на всю ширину viewport. Внутренние отступы шапки padding: 0 48px — такие же, как у .hero-inner. Логотип и заголовок страницы на одной вертикальной оси.
#2 Пункт меню «Параметры» → «Инструменты» Исправить

В навигации отображается устаревшее название «Параметры». Итоговая структура меню:

  • Справочник — dropdown с двумя пунктами: «По юрисдикциям» и «По инструментам» (оба активны, без SOON)
  • Анализ — бейдж SOON, недоступно
  • Ассистент — бейдж SOON, недоступно

Пункты «Главная» и «Каталог параметров» / «Параметры» в меню отсутствуют.

Текущая кнопка «Инструменты» ведёт на /parameters — маршрут нужно будет обновить когда раздел инструментов будет готов. До тех пор оставить как есть или вести на заглушку.

#3 Старые карточки не удалены Исправить

В циклической анимации чередуются два типа карточек: старые (прежняя реализация) и новые (по прототипу). Это создаёт визуальный разнобой и сломанный UX.

  • Удалить старые карточки полностью из компонента анимации.
  • В анимации должны участвовать только карточки нового стиля (по прототипу listing-research-landing-v2.html, блок .preview-panel).
#4 Карточка некликабельна Исправить

Карточка-превью юрисдикции должна быть полностью кликабельной — весь блок ведёт на страницу этой юрисдикции.

/* Вся карточка — ссылка */
cursor: pointer;
transition: border-color .15s, box-shadow .15s;

.preview-panel:hover {
  border-color: rgba(255,255,255,0.22);
  box-shadow: 0 28px 72px rgba(0,0,0,.6);
}

Клик → переход на /jurisdictions/[id] текущей отображаемой юрисдикции.

#5 Карточка: убрать «Орган листинга», показывать все площадки Изменить

Два изменения в содержимом карточки-превью:

5a. Убрать строку «Орган листинга»

Поле содержит длинный текст из базы данных (например, полное описание функции регулятора), который не помещается в карточку и выглядит сломанным. Убрать строку целиком — карточка и без неё несёт достаточно информации.

Сейчас
Строка «Орган листинга» с полным текстом, вылезающим за границы.
Должно быть
Строки «Орган листинга» нет. Остаётся только «Торговых площадок: N».

5b. Показывать все площадки, не только три

Ограничение в 3 площадки было введено в прототипе под тестовые данные с UK (3 площадки). В реальных данных площадок может быть больше — нужно показывать все.

  • Убрать лимит на количество отображаемых чипов площадок.
  • Если площадок много (5+) — карточка растёт в высоту. Добавить max-height и overflow-y: auto на блок площадок, чтобы карточка не вылезала за пределы viewport.
  • Рекомендуемый max-height для блока площадок: 200px.
.venue-list {
  max-height: 200px;
  overflow-y: auto;
  /* scrollbar styling — match existing dark theme */
}
#6 Точки на карте слишком крупные Изменить

При 47 юрисдикциях в базе точки будут очень плотно расположены в Европе и Азии. Крупные точки создадут визуальную кашу.

Сейчас
Точки — круги с radius ~5–6px.
Должно быть
Точки — круги с radius 3px в обычном состоянии. Активная (текущая в анимации) — 5px с мягким свечением (box-shadow / filter glow). Это позволит читать карту при высокой плотности.
/* Обычная точка */
.map-dot {
  r: 3;  /* SVG circle radius */
  fill: rgba(96, 165, 250, 0.7);
}

/* Активная точка (текущая юрисдикция в анимации) */
.map-dot.active {
  r: 5;
  fill: rgba(96, 165, 250, 0.95);
  filter: drop-shadow(0 0 4px rgba(96, 165, 250, 0.6));
}
#7 Итоговая модель поведения карты и карточки Изменить

Это ключевое архитектурное решение по лендингу. Карта — декоративная, не навигационная.

Как должно работать

  • Карточка-превью расположена фиксированно справа (как в прототипе).
  • Карточка циклически листает верифицированные юрисдикции с плавным fade-переходом (~4 секунды на каждую).
  • При смене юрисдикции в карточке — соответствующая точка на карте подсвечивается (становится активной: больше + свечение). Остальные точки — в обычном состоянии.
  • Точки на карте некликабельны. Карта — атмосферный фон, не элемент навигации.
  • Вся карточка целиком кликабельна → переход на страницу юрисдикции (см. #4).

Что убрать

  • Всплывающие карточки у точек на карте (старая реализация) — удалить полностью.
  • Обработчики кликов на точках карты — удалить.
  • Hover-эффекты на точках карты — убрать.

Почему такое решение

Главный заголовок «Глобальный справочник листинговых режимов» занимает левую половину экрана. При 47 юрисдикциях многие точки окажутся под заголовком и будут недостижимы для клика. Лендинг — не навигационная страница: настоящая навигация начинается на следующем экране (список юрисдикций). Задача карты на лендинге — создать ощущение глобального охвата, а задача карточки — показать, что данные реальные и верифицированные.

Итог: одна карточка справа + подсвет активной точки на карте — это минимально достаточная и технически надёжная модель. Она работает при любом количестве юрисдикций и не конфликтует с заголовком.

Что оставить без изменений

  • Тёмная тема лендинга — реализована верно.
  • Текст подзаголовка — обновлён корректно («акций, облигаций, фондов, депозитарных расписок...»).
  • Кнопки «Юрисдикции» (primary) и «Инструменты» (secondary) — правильно.
  • Stats strip с четырьмя ячейками — правильно, оставить.
  • Стиль карточки-превью (новый) — оставить, только с правками из пунктов #4 и #5.
  • Dot-grid текстура фона — оставить.
