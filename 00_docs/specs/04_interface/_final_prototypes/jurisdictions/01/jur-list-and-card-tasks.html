Л-1 Убрать фильтры по статусу данных Убрать

Кнопки «Все данные / Верифицировано / Частично / В работе» — убрать. Их не было в прототипе. Оставить только: поиск + DM/EM + правовая семья.

Л-2 Флаги: emoji вместо буквенных аббревиатур Исправить

Сейчас флаги — цветные круги с кодом страны (AU, GB…). Нужны emoji-флаги, генерируемые из ISO-кода:

const isoToEmoji = code =>
  code.toUpperCase().split('').map(c =>
    String.fromCodePoint(c.charCodeAt(0) + 127397)
  ).join('');
Л-3 Регистр чипов правовой семьи Исправить

Встречается «common law», «Civil law», «civil law» — привести к единому виду строчными. Нормализация на уровне отображения: text-transform: lowercase на чипе.

Л-4 Кнопка «Открыть» — сделать строки кликабельными Исправить

Кнопка «Открыть →» в правой части каждой строки — избыточна. Правильный паттерн для справочной таблицы: вся строка кликабельна, курсор pointer, hover — лёгкий фон #FAFBFF. Кнопку убрать.

Исключение: строки со статусом «В работе» — некликабельны (cursor: default), hover не меняет фон.
