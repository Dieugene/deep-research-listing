# Обратная связь по обновлённому прототипу (v2)

**Дата:** 2026-03-12

## 1. Главная страница

### 1.1. Что улучшилось
- Название: «Listing Research» + «Глобальный справочник листинговых режимов» — существенно лучше, чем «Листинг ЦБ».
- Навигация: появились «Каталог параметров», «Анализ (Скоро)», «Ассистент (Скоро)» — соответствует спецификации.
- Метрики: 47/65/4/~1000 — показывают масштаб замысла, не текущую пустоту. Правильно.
- Карточки разделов: неактивные имеют пояснение «после сбора данных по 10+ юрисдикциям» — хорошо.

### 1.2. Глобус → плоская карта

**Проблема:** Крутящийся 3D-глобус — эффектно на первый взгляд, но функционально неудобно. Чтобы увидеть нужную юрисдикцию, нужно ждать, пока глобус довернётся. При 47 точках, раскиданных по всему миру, это потеря времени.

**Решение:** Заменить на полную карту мира (все юрисдикции видны сразу). Проекция — стандартная (Natural Earth или Equirectangular), допустим лёгкий наклон для визуального эффекта, но не обязателен. Главное — все 47 точек видны одновременно, без ожидания.

**Анимация:** Вместо вращения глобуса — автоматически чередующиеся всплывающие плашки (tooltip) по каждой юрисдикции. Каждые 3–4 секунды плашка появляется у новой точки, задерживается на 2–3 секунды, затем появляется у следующей. Порядок — произвольный или по регионам.

Поведение при наведении курсора: если пользователь навёл курсор на точку — плашка этой юрисдикции появляется и не исчезает, пока курсор наведён. Автоматическая ротация приостанавливается. Когда курсор убран — ротация возобновляется.

### 1.3. Hover-плашки — содержание и ссылки

**Баг:** При наведении на Гонконг и UK показано «0 площадок». Нужно исправить — данные о площадках есть в базе (UK: 3, HK: 2).

**Содержание плашки:**
- Название юрисдикции (рус + англ)
- Количество площадок
- **Перечень площадок — названия, каждое — кликабельная ссылка** (переход на страницу площадки)
- Правовая семья
- Клик по названию юрисдикции (заголовок плашки) → переход на страницу юрисдикции

Плашка должна быть достаточно просторной для 2–3 площадок с названиями-ссылками. Оформление: аккуратная типографика, мягкая тень, fade-in при появлении.

### 1.4. Убрать пунктирные линии между точками

Пунктиры между точками на карте не несут информации (нет содержательного основания для связи). Убрать. В будущем, когда появятся кластеры, можно будет показывать тонкие линии между юрисдикциями одного кластера — но не сейчас.

### 1.5. Кнопка «Параметры» рядом с «Открыть справочник»

Слово «Параметры» на кнопке по-прежнему может путать (ассоциация с настройками). Лучше: «Сравнить параметры» или «Каталог требований».

## 2. Карточка юрисдикции (UK)

### 2.1. Маппинг терминов — столбцы перепутаны

**Проблема:** Столбец «Термин ядра» содержит местные (UK) термины: «Official listing», «Admission to trading», «Recognised Investment Exchange (RIE)» и т.д. Столбец «Местный термин» содержит расшифровку/описание этих же местных терминов. Это наоборот.

**Как должно быть:**

| Понятие исследования | Местный термин (UK) |
|---------------------|---------------------|
| Официальный листинг (Г02) | Official listing — Inclusion on the FCA's Official List under FSMA Part VI |
| Допуск к торгам (Г03) | Admission to trading on a specific venue under its rulebook |
| Оператор площадки (Б02) | Recognised Investment Exchange (RIE) |
| Правила листинга | UK Listing Rules (UKLR) — FCA UK Listing Rules sourcebook |

Левый столбец — понятия из нашей концептуальной модели (нейтральные, одинаковые для всех юрисдикций). Правый — как это называется конкретно в UK.

### 2.2. «Термин ядра» — переименовать

**Проблема:** «Термин ядра» — внутреннее понятие разработчиков (ядро = концептуальное ядро исследования). Для пользователя интерфейса это непонятно.

**Варианты замены:**
- «Понятие исследования» / «Research concept» — нейтрально
- «Стандартное понятие» / «Standard term» — подчёркивает нейтральность
- «Категория» — самый простой вариант

Рекомендация: **«Понятие исследования»** — точно отражает функцию (это понятие из нашего метаязыка, на которое маппится местный термин).
