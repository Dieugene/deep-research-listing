## Регистр предпосылок отображения — вставка от направления «Институциональные факторы»

Предпосылки, выявленные при проработке набора институциональных факторов для конфигурационного анализа. Передаются в направление «Информационная архитектура / интерфейс».

**Источник:** Диалог «Набор институциональных факторов для сравнительного анализа», 05.03.2026.

| # | Предпосылка | Источник / обоснование |
|---|-------------|----------------------|
| 1 | Карточка юрисдикции (уровень 1) должна содержать блок институциональных факторов — 12 полей, сгруппированных в 4 блока: правовая система (Ф1–Ф3), качество институтов (Ф4–Ф6), структура рынка (Ф7–Ф10), архитектура регулирования (Ф11–Ф12). | Операционализация v0.1 |
| 2 | Факторы имеют разные типы шкал: категориальные (Ф1, Ф3, Ф8–Ф12), непрерывные индексные (Ф4–Ф6, шкала −2.5…+2.5), непрерывные процентные (Ф7), непрерывные 0–1 (Ф2). Интерфейс должен корректно отображать каждый тип. | Операционализация v0.1 |
| 3 | Блок II (Ф4–Ф6) — три индекса WGI по единой шкале. Целесообразно отображать как единый визуальный элемент (например, radar chart или grouped bar) с возможностью свёртки в композитный индекс. | Операционализация v0.1, раздел «Блок II» |
| 4 | Кластеризация юрисдикций по значениям факторов — отдельная точка входа в интерфейс. Пользователь должен видеть, какие юрисдикции имеют сходные институциональные условия, до перехода к сравнению конкретных параметров режимов. | Рекомендация Рейгина (конфигурационный подход); контекст: «Точка 1 — кластеризация» |
| 5 | Институциональные факторы и справочные данные (матрица 4×5) — разные слои отображения, связанные перекрёстными ссылками. Фактор объясняет параметр, но не перемешан с ним. Пример: пользователь видит «free float = 10%», нажимает «почему» → видит значения Ф8 (концентрация владения) и Ф3 (private enforcement) для данной юрисдикции. | Рекомендация Тафти (архитектурный слой через отдельные точки входа); контекст диалога |
| 6 | Фактор Ф10 (конкурентная структура площадок) помечается в интерфейсе как авторская шкала (research gap в литературе). Это влияет на визуальное оформление: например, иной стиль или сноска. | Обзор литературы Consensus; раздел 3.4 обзора |
| 7 | При отсутствии данных по фактору — явная индикация «данные не получены» (не пустое поле и не «0»). Особенно критично для Ф2 (ASDI, покрытие 72 юрисдикции) и Ф9 (неоднородные данные). | Операционализация v0.1, раздел «Риски» |
| 8 | Outcome variable (приток акционерного капитала + защита розничных инвесторов) — отображается как целевой показатель, к которому привязана конфигурация факторов. Визуально: конфигурация факторов → стрелка → outcome. | Контекст: регуляторные цели БР, раздел 4.1 |
| 9 | Small multiples (рекомендация Тафти) — шаблон карточки юрисдикции должен быть единым для всех юрисдикций. Институциональные факторы определяют, какие поля входят в этот шаблон. Шаблон нельзя спроектировать до фиксации набора факторов. Набор зафиксирован (v0.1, 12 факторов). | Контекст предыдущих диалогов; рекомендация Тафти |
| 10 | Для блока IV (Ф11, Ф12) — пограничный статус (институциональный / регуляторный) должен быть визуально обозначен, чтобы пользователь понимал: эти характеристики одновременно описывают среду и являются частью регуляторной архитектуры. | Диалог: обсуждение границы институциональных и регуляторных факторов |
