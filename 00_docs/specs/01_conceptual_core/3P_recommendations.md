# Рекомендации для доразведки по методикам расчётов

Следующий шаг после извлечения структуры параметров (Pass 1) и значений (Pass 2) — уточнение методик расчёта тех параметров, где конструкция сложная или неоднозначная.

### Какие параметры требуют доразведки методик

Не все. Доразведка нужна для параметров, где ответ на вопрос 2 шаблона («HOW IS IT CALCULATED?») в результатах Pass 1 содержит одно из:
- Ссылку на внешний документ без раскрытия содержания («calculated per DDES methodology», «as defined in SFO Schedule 1»)
- Неоднозначность в исключениях («holdings above certain thresholds are excluded» — каких именно?)
- Упоминание нескольких альтернативных методик без детализации

### Приоритетные кандидаты (по опыту пилота)

| Параметр | Что уточнять | Почему |
|---|---|---|
| П01 (free float) | Точный перечень исключений: порог отсечения (>5%? >10%?), казначейские акции, lock-up, перекрёстное владение. Кто верифицирует расчёт | Критический для сравнения: одно и то же число 25% означает разное при разных исключениях |
| П02 (min market cap) | Методика расчёта: средневзвешенная за N дней? на дату подачи? по цене размещения? | Влияет на сопоставимость порогов |
| П08 (profit test) | Какие именно показатели: чистая прибыль, операционная, EBITDA? За какой период, кумулятивно или нет | Различия в определении «прибыли» делают числа несопоставимыми |
| П20 (min denomination, bonds) | Связь с П32 (investor eligibility): €100K denomination = de facto professional only | Связка параметров, критична для понимания режима |
| П35 (guarantor eligibility) | Методика: те же тесты, что для эмитента, или отдельные? Какой собственный капитал, за какой период | Пока только HK; при масштабировании — сравнение |

### Формат запроса для доразведки

Доразведка — точечный запрос по конкретному параметру, а не широкий поиск. Промпт должен содержать:
1. Результат Pass 1 по данному параметру (то, что уже известно)
2. Конкретный вопрос: что именно неясно
3. Указание на тип источника: для методик расчёта — rulebook биржи, guidance notes регулятора, а не аналитические отчёты

```
TEMPLATE — Methodology drill-down:
Parameter: [ID and name]
Jurisdiction: [jurisdiction]
What is already known: [paste Pass 1 description]
What needs clarification: [specific question]
Preferred source type: exchange rulebook, regulator guidance, or official
methodology document. Do NOT use secondary analytical sources.
```

### Связки параметров

При доразведке фиксировать связки, выявленные в Pass 1 (вопрос 5 шаблона). Типичные:
- П04 (min price) × П05 (min shares) = неявный денежный порог
- П20 (min denomination) → П32 (investor eligibility): высокий номинал = de facto professional only
- П01 (free float) ↔ П02 (min market cap free float): процент и абсолютная стоимость как альтернативы
- П15 (market maker) → П03 (min shareholders): наличие маркет-мейкера снижает порог по числу акционеров

Доразведка по одному параметру из связки должна включать вопрос о втором: «Does the calculation of [parameter A] depend on or interact with [parameter B]?»

### Чего не делать

- Не запускать доразведку по всем параметрам. Только по тем, где Pass 1 дал неполный ответ на вопрос 2 (методика) или вопрос 5 (связки).
- Не использовать доразведку для заполнения `data_not_found`. Если параметр не найден в Pass 1 — это либо `not_applicable`, либо проблема с L3-данными. Доразведка методики предполагает, что параметр уже найден, но его конструкция недостаточно описана.
- Не запрашивать методику по бинарным параметрам (П31 — eligibility preconditions). Там нечего уточнять: либо выполнено, либо нет.
