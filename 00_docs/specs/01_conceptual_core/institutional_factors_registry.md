# Реестр институциональных факторов
## Выявлены при формировании концептуального ядра v0

**Дата:** 2026-03-04
**Статус:** Предварительный перечень для последующей проработки в отдельном направлении.
**Источник:** Концептуальное ядро v0 + контекст предыдущих диалогов (рекомендация Рейгина: 6–8 факторов для конфигурационного анализа).

Данный реестр — не готовый инструмент, а перечень кандидатов. Требуется отдельная проработка: определение шкал, значений, источников данных.

## Факторы, выявленные из концептуального ядра

| # | Фактор | Источник в ядре | Что фиксирует | Предварительная шкала |

| 1 | **Архитектура допуска: разделение листинга и допуска к торгам** | Г04 | Являются ли официальный листинг и допуск к торгам разными правовыми институтами | Объединённый / раздельный / смешанный |
| 2 | **Модель листингового органа** | Б02, Б03, Б04 | Кто принимает решение о листинге: биржа, регулятор, отдельный орган | Биржа = листинговый орган / Регулятор = листинговый орган / Отдельный орган |
| 3 | **Тип регулятора** | Б04 | Институциональная форма регулятора рынка ценных бумаг | Центральный банк / Отдельная комиссия / Наднациональный + национальный (EU) |
| 4 | **Роль биржи как SRO** | Б02, примечание | Обладает ли биржа квазирегуляторными полномочиями саморегулируемой организации | Да (SRO) / Частично / Нет |

| 6 | **Наличие тиерированного листинга** | А05, примечание | Существует ли иерархия уровней листинга с различающейся строгостью | Да (≥2 уровней) / Нет (плоская структура) — фиксируется по классам инструментов |
