# Допуск и листинг ценных бумаг — глобальное исследование

Многоуровневый пайплайн Deep Research для сбора и структурирования данных о требованиях к листингу и допуску к торгам ценных бумаг по 47 юрисдикциям и ~65 биржевым площадкам. Пайплайн включает 4 уровня сбора данных (юрисдикция → площадка → ячейка → проблемно-ориентированный анализ) с LLM-постобработкой на каждом уровне и пакетной классификацией по словарю параметров (П01–П23). Результат сохраняется в JSON-файлах и загружается в PostgreSQL.

## Цель

Создать структурированную сравнительную базу данных регуляторных требований к листингу ценных бумаг в глобальном разрезе — как фундамент для анализа регуляторных паттернов, выявления связей параметров с регуляторными целями и поддержки работы по оптимизации российского регулирования.

## Архитектура пайплайна

```
Предварительный этап   — институциональные факторы по всем 47 юрисдикциям
Уровень 1 (47 шт.)    — архитектура допуска, факторы, ландшафт площадок
Уровень 2 (~65 шт.)   — детальная структура площадки, генерация ячеек
Уровень 3 (~1000 шт.) — сбор данных по ячейкам (3А первичный допуск,
                         3Б негативные аспекты, 3В enforcement, 3Г вторичный)
Пакетная постобработка — маппинг на словарь параметров П01–П23, перевод
Уровень 4 (47 шт.)    — проблемно-ориентированный анализ, регуляторные цели
Загрузка в PostgreSQL
```
